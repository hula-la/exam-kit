# 질문과 답변을 그때그때 반영

질문 초안:
- 기존 자료와 이미 받은 답을 먼저 확인한다. 답에 따라 설계·판정·범위가 바뀌는 질문만 우선한다.
- 질문마다 근거 위치·달라지는 결정·추천 이유를 한 줄씩 붙인다. 처음에는 영향이 큰 2~3개부터, 결과를 바꾸지 않으면 질문을 멈춘다.
- 사용자가 내용을 확인해 보내게 한다. 자기 말로 다시 쓰기를 강제하지 않는다. 명시적 발송 요청이 없다면 메시지는 초안으로만 둔다.

새 답변을 받았을 때:
1. sources/dialogue.md에 Q001 같은 번호로 질문·답변 원문을 추가한다. 질문이 이미 있으면 그 번호에 답을 연결한다. 화자·시각은 주어진 것만 쓰고 없으면 미상으로 둔다.
2. 질문과 답이 짧아도 한 턴씩 바로 처리한다. 여러 조각으로 나눠 보내겠다고 한 경우에만 전달 완료를 기다린다. 똑같은 답은 중복으로 연결하며 다시 적용하지 않는다.
3. 사실·담당자 답·사용자 결정·AI 제안·가정·폐기를 구분한다. 최신 발언이라는 이유만으로 공식 요구를 덮어쓰지 말고 권한·적용 시점·현재 요청을 본다.
4. 현재 유효한 규칙만 notes/spec.md에 근거와 함께 갱신한다. 바뀐 결정과 진행·실제 검증·다음 행동은 notes/work.md에 짧게 기록한다.
5. 결과를 바꾸는 충돌·모호한 승인만 질문한다. 미확정에 의존하지 않는 합의된 작업은 계속한다. 담당자가 없으면 미확정·잠정 가정과 영향을 표시한다. 답이 없다는 이유로 승인 처리하지 않는다.
6. 출력은 변경된 것 / 유지·미확정 / 다음 행동, 필요한 결정만 짧게 쓴다. 전체 문서를 매번 다시 출력하지 않는다.

# 빠른 진행 점검 — 필요한 것만

- [ ] AI가 원문을 읽고 현재 목표·필수 제출·제약·미확정을 정리했다.
- [ ] 중요한 질문에 받은 답을 그때그때 전달했고, 제약·우선순위를 결정했다.
- [ ] 필요하면 작은 예제 HTML로 알고리즘을 먼저 이해했다.
- [ ] 작은 실제 결과와 필수 실행환경을 일찍 확인했다.
- [ ] 구현·분석과 검증·수정을 반복했고 실제 결과·미확인을 구분했다.
- [ ] 최종 코드·결과에 설명 HTML과 문서를 맞추고 내 말로 설명했다.
- [ ] 실제 안내의 필수 파일·형식·제출 상태를 확인했다.

모든 스킬 호출·매 단계 승인·사람의 재작성은 필수가 아니다.

# 새 채팅에서 이어가기 · 짧은 인계

이 작업을 이어가 줘. 기존 지침을 읽고 notes/spec.md와 notes/work.md부터 확인해.
실제 코드·파일·현재 실행 환경을 대조한 뒤, 필요한 근거 원문만 sources/에서 찾아. 과거 AI의 완료 보고를 현재 검증으로 취급하지 마.
기존 유효한 결정은 유지하되 충돌·폐기된 안·미확정 조건을 구분해. 내 현재 요청이 기존 기준과 충돌하면 무엇이 달라지는지 짚어.
지금 목표 / 확정 제약·목표 순서 / 검증된 것·미확인 / 다음 행동을 짧게 말하고 이미 합의한 범위의 작업을 이어가.
모든 대화를 매번 다시 요약하거나 파일을 새로 만들 필요는 없어. 결과를 바꾸는 미확정 사항만 물어.
작업 후 spec.md에는 규칙의 변경만, work.md에는 실제 결과·다음 행동만 반영해.
(파일 접근이 없는 AI라면 내가 spec.md와 work.md를 먼저 붙이고 필요한 원문·코드·로그만 추가로 전달한다. 접근하지 못한 파일을 읽었다고 하지 마.)

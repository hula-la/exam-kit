# 알고리즘 처음 이해하기 · HTML 요청

현재 notes/spec.md와 알고리즘 초안/코드를 읽고 docs/algorithm.html을 만들어 줘.
외부 라이브러리·CDN 없이 파일을 열면 보이는 단일 HTML로, 이해에 필요한 표·간단한 SVG와 이전/다음 단계 버튼만 써. 디자인보다 계산 과정을 우선해.
상단에 설계 가설/구현 확인 중 중 무엇인지, 확인한 코드 경로·함수·버전 또는 작성 시점을 표시해. 구현 전 예시는 교육용 가정이라고 적어.
작은 입력 하나의 ID·단위·시간 기준 → 필수 제약과 목표 순서 → 중간 상태 → 후보 탈락 이유 → 선택 결과를 단계별로 보여 줘. 입력·중간값·결과를 숨기지 마.
우선순위를 바꾸면 선택이 달라지는 사례와 제약을 위반하는 반례를 보여 줘. 정해진 예시를 전환하는 것인지 실제 계산하는 것인지 표시해.
현재 탐색에서 못 찾음과 불가능 입증을 구분하고, 휴리스틱이면 전역 최적을 보장한다고 쓰지 마.
복잡한 구현을 단순화했다면 생략한 조건과 실제 코드의 차이를 적어. 시각화에 별도 알고리즘을 다시 만들어 실제 코드처럼 보이게 하지 마.
끝에 내가 답할 질문 3개와 접어서 볼 수 있는 해설을 넣어: 왜 이 후보인가 / 무엇을 바꾸면 결과가 바뀌나 / 무엇을 검증해야 하나.
먼저 최소 설명을 만들어 줘. 나는 정상 예시 하나와 반례 하나를 따라 계산하고 이해가 막힌 곳만 질문할게. 이 HTML 자체를 검증 통과 증거로 쓰지 마.

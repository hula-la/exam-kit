1. 기존 지침·sources/·notes/spec.md·notes/work.md를 확인하고 이번 원문을 sources/chat-NNN.md의 다음 번호에 보존해. 기존 원문은 덮어쓰지 마. 새 대화와 겹치는 부분은 중복으로 연결하고 같은 결정을 다시 적용하지 마.
2. 화자·시각·대화 구분은 주어진 것만 써. 없으면 미상으로 표시하고 순서·승인·출처를 추측하지 마. 길어서 나눠 붙이면 내가 [전달 끝]이라고 할 때까지 원문 저장과 누락 확인만 해.
3. 사실 / 담당자 답변 / 내 결정 / AI 제안 / 가정 / 폐기된 안을 구분해. AI의 이전 답변은 검증할 주장이지 승인이나 실행 증거가 아니야.
4. 현재 유효한 요구·제약·목표 순서·미확정만 notes/spec.md에 반영하고 원문 파일과 발언 위치를 연결해. 최신 발언이라는 이유만으로 공식 제약을 덮어쓰지 마. 권한 있는 변경인지·적용 시점·현재 내 지시와의 관계를 확인해. 충돌이 해결되지 않았으면 병렬로 남기고 결과를 바꾸는 질문만 해.
5. 완료했다는 과거 발언은 실제 코드·파일·명령 결과와 대조해. 지금 확인할 수 없으면 과거 보고/현재 미확인으로 적어. 실제 검증과 다음 행동은 notes/work.md에 기록하고 요구사항 본문은 중복하지 마.
